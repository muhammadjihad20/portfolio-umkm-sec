# UMKM Digital Ledger & Security Audit Platform (MVP)

## Overview
A web-based information system designed to help local Micro, Small, and Medium Enterprises (MSMEs) manage transaction records while implementing Role-Based Access Control (RBAC) and continuous security auditing based on OWASP Top 10 standards.

## Architecture & Security Focus
- **Multi-Role Authentication:** Admin, MSME Owner, and Security Auditor.
- **Security Testing Integration:** Built-in test cases for Broken Access Control (IDOR & Privilege Escalation).
